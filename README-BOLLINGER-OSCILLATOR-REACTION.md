# Bollinger Band + Oscillator Reaction

Versi ini menambahkan pembacaan otomatis pada panel FINAL SIGNAL untuk candle 5M yang sudah tertutup:
- Bollinger Bands 20 periode, 2 deviasi: lower-band rejection, upper-band rejection, breakout, dan breakdown.
- RSI 14: kondisi ekstrem serta cross balik melewati 30/70.
- MACD 12/26/9: perubahan histogram dan perpotongan garis.
- StochRSI 14/3/3: golden/dead cross di area ekstrem.

Konfluensi ditampilkan sebagai LONG/SHORT/NEUTRAL dan disertakan dalam alasan Final Signal. Ini merupakan faktor konfirmasi dan peringatan, bukan jaminan harga akan berbalik. Menyentuh Bollinger Band saja tidak otomatis berarti reversal; breakout dapat berlanjut. Sinyal tetap hanya notifikasi/manual, tidak mengirim order live otomatis.
