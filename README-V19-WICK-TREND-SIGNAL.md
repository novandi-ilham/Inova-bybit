V19 - WICK + TREND SIGNAL REVISION

Signal selection now scores the last three completed candles' upper/lower wicks, candle body/close location, EMA position/slope, and recent momentum together. It no longer requires the volume threshold, anti-chase threshold, S/R proximity, extreme-volatility regime, and 55-point threshold all to pass before showing BUY/SELL. Mixed/near-doji conditions can still return HOLD.

This changes signal bias/notifications only; it does not guarantee a profitable outcome or alter the manual-entry policy. Signals are heuristic estimates, not certainty. Validate in PAPER mode and inspect PnL/fees/SL/TP before relying on it.
