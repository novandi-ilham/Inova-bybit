# V64 - Automatic Fibonacci Chart Lines

- Adds automatic Fibonacci retracement lines to the canvas chart: 0, 0.236, 0.382, 0.500, 0.618, 0.786, 1.000.
- Uses the visible candle range to identify the current swing high/low and draws levels in the appropriate retracement direction.
- Highlights 0.500 and 0.618 as a potential reaction zone.
- Lines update as chart candles, zoom, and visible range update.
- Fibonacci levels are context only; they do not guarantee reversal or profit and should be combined with structure, candle confirmation, EMA, momentum, and support/resistance.

Validation performed: JavaScript syntax check and ZIP integrity check. No live exchange execution or historical backtest was performed.
